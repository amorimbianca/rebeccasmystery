# ETAPA 04 — COMPONENTES E INTERFACE
## Projeto: Rebecca's Mystery

Atue como um Desenvolvedor Front-end Sênior e UI/UX Designer especializado em interfaces digitais de alto padrão.

Sua missão é aprimorar e implementar os componentes da interface do site Rebecca's Mystery, respeitando integralmente a identidade visual e o layout definidos nas etapas anteriores.

Não quero componentes com aparência de bibliotecas prontas ou templates genéricos. Cada elemento deve parecer parte de um projeto desenvolvido por um estúdio profissional.

## 1. DIREÇÃO VISUAL

Todos os componentes devem seguir:

- Identidade visual de Rebecca's Mystery.
- Cores principais #1a0612 e #b77b9b.
- Tipografia definida nas etapas anteriores.
- Linguagem editorial e cinematográfica.
- Composição sofisticada e contemporânea.
- Hierarquia visual consistente.

Os componentes precisam complementar o layout, nunca competir com ele.

## 2. MENU E NAVEGAÇÃO

Desenvolva um menu elegante, funcional e integrado à identidade do site.

Requisitos:
- Logo oficial RM.
- Links para as seções principais.
- Estado visual para a seção ativa, quando aplicável.
- Menu responsivo para dispositivos móveis.
- Transições suaves e discretas.
- Boa legibilidade em todos os fundos.

O menu não deve ocupar espaço visual desnecessário.

## 3. BOTÕES

Crie um sistema de botões consistente.

Inclua:
- Botão principal de jogar.
- Botões secundários.
- Links com aparência de ação.
- Estados de hover, foco, pressionado e desabilitado, quando necessário.

Os botões devem ter personalidade visual, sem exageros.

O botão de jogar precisa manter o destino real do jogo. Não invente links.

## 4. GALERIA DE PERSONAGENS

Aprimore a interação dos personagens.

A apresentação deve ser integrada ao layout editorial definido anteriormente.

Quando houver interação:
- Utilize transições discretas.
- Apresente informações de forma organizada.
- Mantenha boa legibilidade.
- Permita navegação por teclado.
- Evite animações que atrapalhem a leitura.

Não transforme os personagens em cards genéricos.

Não invente personagens, imagens ou informações.

## 5. ELEMENTOS DE CONTEÚDO

Desenvolva padrões visuais para:
- Títulos e subtítulos.
- Textos de apresentação.
- Frases de impacto.
- Dados estatísticos.
- Legendas de imagens.
- Links e chamadas de ação.

Crie variações de composição para que o site não pareça repetitivo.

## 6. INTERAÇÕES

Implemente interações que tenham uma função clara.

Exemplos:
- Hover em botões e links.
- Revelação de informações dos personagens.
- Navegação entre seções.
- Transições entre estados da interface.
- Feedback visual para ações do usuário.

As interações devem ser suaves, rápidas e naturais.

Não adicione efeitos apenas para deixar a página movimentada.

## 7. RESPONSIVIDADE DOS COMPONENTES

Garanta que todos os componentes funcionem em:
- Computadores.
- Tablets.
- Celulares.

Adapte tamanhos, espaçamentos, alinhamentos e interações conforme o dispositivo.

Não basta reduzir tudo proporcionalmente: reorganize os elementos quando necessário.

## 8. ACESSIBILIDADE E QUALIDADE

- Utilize HTML semântico.
- Garanta contraste adequado.
- Inclua estados de foco visíveis.
- Permita navegação por teclado.
- Utilize textos alternativos nas imagens.
- Evite elementos interativos sem identificação.
- Respeite a preferência por redução de movimento.
- Não prejudique a performance.

## 9. REGRAS IMPORTANTES

- Trabalhe diretamente no projeto existente.
- Reaproveite componentes quando fizer sentido.
- Não duplique estruturas desnecessariamente.
- Não remova funcionalidades existentes.
- Não altere a história ou o conteúdo do jogo.
- Não crie informações fictícias.
- Não adicione elementos decorativos sem propósito.
- Preserve as decisões das etapas anteriores.

## 10. RESULTADO ESPERADO

Quero componentes refinados, funcionais e visualmente coerentes com o restante do site.

Cada elemento deve ter uma função e uma razão estética para existir.

Revise a interface completa, teste as interações e corrija inconsistências antes de finalizar.

Execute somente esta etapa e aguarde autorização para avançar.
